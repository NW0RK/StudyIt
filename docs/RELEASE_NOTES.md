# StudyIt 1.0.3

- Professional English, Blockchain, and Game Dev replace the starter subjects.
- Twelve English for Computing discussions are included for offline reading.
- The shared library refreshes at launch, with Refresh, and when returning to the app after five minutes.
- Android checks for new app versions daily. Use **Check for app updates** to check immediately.
- **Update app** downloads and verifies the APK, then opens Android's installer. Android may ask you to allow StudyIt to install apps; return to StudyIt afterward to continue.
- Failed downloads and content refreshes retain existing reading data. Bookmarks, follows, and theme preferences survive compatible app upgrades.

Download **StudyIt.apk** for Android 7.0 or newer (64-bit ARM devices and x86-64 emulators). Install over the previous version to retain local data. This release retains the existing preview signing identity and is distributed directly through GitHub.

The APK checksum is provided in **StudyIt.apk.sha256**. **android-update.json** supplies version and integrity information for future in-app updates.
